=================================================================
ROOT CAUSES QUICK SUMMARY
=================================================================

1. Context Rebuilding with Original Request
   File: coordinator_agent.py
   Line: 415
   Method: _build_context()
   Issue: input_text always included, causes re-reading of full task

2. Full Re-Planning Every Iteration
   File: coordinator_agent.py
   Lines: 296-344
   Method: _run_with_trace()
   Issue: Calls _create_plan() every iteration asking for FULL plan
   
3. No Safeguard Against Perpetual "Continue" Decisions
   File: coordinator_agent.py
   Lines: 333-340
   Method: _run_with_trace()
   Issue: No counter for consecutive "continue" responses
   Compare: ReasoningAgent has this (reasoning_agent.py:883-894)

4. Subagents Receive Full Original Request
   File: coordinator_agent.py
   Lines: 583-587
   Method: _execute_step()
   Issue: enriched_input includes original_request, not just step
   Result: Subagent sees full task scope, not just its assignment

5. Plan Execution Skip Logic May Fail
   File: coordinator_agent.py
   Lines: 513-520
   Method: _execute_plan()
   Issue: If plan recreated with different step_numbers, skip fails

=================================================================
QUICKEST FIXES
=================================================================

All fixable in ~30 minutes:

1. Add "continue" counter - 5 mins
   Location: coordinator_agent.py, lines 333-340
   Impact: HIGHEST - prevents most infinite loops

2. Remove original_request from subagent input - 10 mins
   Location: coordinator_agent.py, lines 583-587
   Impact: HIGH - reduces scope creep

3. Add "replan" counter - 5 mins
   Location: coordinator_agent.py, lines 335-337
   Impact: MEDIUM - prevents replan loops

4. Limit history in context to last 3-5 items - 5 mins
   Location: coordinator_agent.py, lines 436-440
   Impact: MEDIUM - cleaner context for LLM

5. Add consecutive decision counter - 5 mins
   Location: coordinator_agent.py, main loop
   Impact: MEDIUM - forces completion after 3+ same decisions

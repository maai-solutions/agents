=== CONTEXT PROPAGATION ISSUES ===

1. ORIGINAL REQUEST APPEARS IN EVERY ITERATION
   - Coordinator always includes input_text in context
   - Each subagent gets original request, not just their step
   - This can cause subagents to expand their scope

2. HISTORY GROWS WITHOUT BOUND
   - execution_history.extend(step_results) keeps growing
   - Each new plan includes "last 10 items" which keeps the history visible
   - Context window fills up quickly

3. PLAN RE-CREATION EVERY ITERATION
   - Each iteration asks LLM: "Create complete plan for X"
   - Not: "What's the next step given we've done X, Y, Z?"
   - LLM might plan differently each time

4. STEP_NUMBER TRACKING ACROSS ITERATIONS
   - In iteration 2+, if LLM creates different plan with different step numbers
   - The skip logic (based on step_number matching) might fail
   - Could lead to re-executing steps

5. EVALUATION DECISION AMBIGUITY
   - Evaluation asks: "Is task complete? Is plan still valid?"
   - If LLM says "continue" or "replan", loop continues indefinitely
   - No maximum successive "continue" checks

=== WHEN DOES IT LOOP INFINITELY? ===

Infinite Loop Condition:
  while not is_complete and iteration < max_iterations:
    - is_complete never becomes True
    - evaluation_result["next_action"] never returns "complete"
    
Causes:
  1. Evaluation prompt unclear -> LLM keeps saying "continue"
  2. History grows but evaluation doesn't recognize completion
  3. Different step_numbers in each plan -> skip logic doesn't work
  4. Subagent's own internal loop doesn't complete (if subagent also has issues)

=== COMPARISON: REASONINGAGENT (WORKS BETTER) ===

REASONINGAGENT LOOP:
  while not is_complete and iteration < max_iterations:
    reasoning = await _reasoning_call(context)
    # reasoning asks: "What TASKS REMAIN to be done?"
    # Not: "What's the FULL PLAN?"
    
    for task in reasoning.tasks:
      result = execute_task(task)
    
    completion = await _check_completion(input_text, history)
    # check_completion has SAFEGUARDS:
    # - If same tool called 3+ times in a row, force complete
    # - Explicit check for repetitive behavior

COORDINATORAGENT LOOP:
  while not is_complete and iteration < max_iterations:
    plan = await _create_plan(context)
    # plan asks: "What's the COMPLETE PLAN?"
    # Re-creates everything from scratch each iteration
    
    execute_plan(plan)
    
    evaluation = await _evaluate_progress(...)
    # evaluation asks: "Is it complete? Should we replan?"
    # No safeguard against perpetual "continue" decisions
